# 第四部分：易混淆概念

## 27. LLM、Agent、编排器

| 概念 | 本质 | 类比 |
|---|---|---|
| LLM | 语言理解与生成能力 | 大脑组件 |
| Agent | 围绕目标执行任务 | 办事员 |
| 编排器 | 协调步骤、状态和审批 | 项目经理 |

```text
LLM 可以没有 Agent。
Agent 通常使用 LLM。
复杂 Agent 流程通常需要编排器。
```

## 28. 工具调用与 MCP

```text
工具调用：我要调用 get_order_status。
MCP：这个工具如何被统一描述、发现和连接。
```

## 29. Fake、Real、Live

```text
Fake：验证逻辑。
Real：验证真实集成。
Live：验证真实条件下的完整使用路径。
```

## 30. EARS、AC、测试、Demo

```text
EARS：写清系统应该如何行为。
AC：定义什么叫完成。
测试：自动验证完成条件。
Demo / Live Eval：在接近真实的条件下展示证据。
```

## 31. Guardrail 与 HITL

```text
Guardrail：系统整体的安全边界。
HITL：在特定节点让人确认。
```

HITL 是 Guardrail 的一种方式，但输入校验、工具白名单和输出脱敏也属于 Guardrail。

## 32. 单元测试与测试契约

```text
单元测试：某段代码是否正确。
测试契约：多个实现之间的接口行为是否一致。
```

## 33. 脚手架与 Skill

```text
脚手架：快速搭项目。
Skill：快速采用一套成熟工作方式。
```
