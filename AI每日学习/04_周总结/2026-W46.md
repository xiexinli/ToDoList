## 2 本周知识主线（复习提纲，不是用户复述）
```text
RAG 找到了资料
  → 引用：每条答案能否指向支持它的片段？（11-09）
  → 评估：固定测试集，区分检索失败和生成失败。（11-10）
Agent 可以行动
  → 循环：真实观察决定下一步，代码设终止边界。（11-11）
  → 记忆：哪些信息注入上下文，哪些要持久保存？（11-12）
  → 规划：先拆目标，执行结果不能被计划替代。（11-13）
  → 护栏：能看见、能限制、能停止交还控制权。（11-14，旧示例待复核）
  → 恢复：进程退出后验证身份与版本，再续跑安全步骤。（11-15）
```

区分三个容易混淆的「保存」：
- Memory 管「模型下一轮看到什么信息」。
- trace 管「发生过什么、为什么失败」。
- checkpoint 管「下一进程能够复用哪些已提交结果」。
