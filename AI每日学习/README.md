# AI 每日学习

每天 2 小时，早晨 8:00 由「AI 学习教练」智能体产出一份学习材料（笔记 + 代码片段）。

## 目录约定
| 目录 | 用途 |
|---|---|
| `00_进度/` | 进度与去重台账（progress.md、动态链接去重表） |
| `01_地基/` | 轨道 1：AI 开发通用底座（LLM 调用 / Prompt / RAG / Agent） |
| `02_AndroidAI/` | 轨道 2：Android × AI（端侧推理 / ML Kit / 端云协同） |
| `03_动态与机会/` | 行业动态、开源项目、岗位观察 |
| `04_周总结/` | 每周把当周内容压成一页摘要（记忆锚点） |

## 文件命名
`YYYY-MM-DD-主题.md`，例如 `2026-10-30-什么是上下文窗口与Token.md`

## 阶段排期
- 第 1 个月（轨道 1）：W1 LLM 基础与 API 调用 → W2 Prompt 工程与工具调用 → W3 RAG 全链路 → W4 Agent 与工程化
- 第 2 个月起（轨道 2）：端侧推理（MediaPipe / TFLite / Gemini Nano）→ ML Kit 系统能力 → 端云协同与降级

## 纪律
1. 每天必须写下「用自己话复述」的一段，不许抄。
2. 动态与机会每天限量（新动向 ≤2 条 + 岗位 1 条 + 其他 1 条），每条必须带来源链接。
3. 每周日额外产出一份周总结。
