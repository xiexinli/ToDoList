## 1 概念精讲（30 min）
- **一句话定义**：能力门禁是把某个端侧功能的**当前证据 + 应用约束**转成「可尝试／需准备／暂缓／不支持」的纯决策，而不是推理成功承诺。
- **它解决什么问题 / 为什么现在必须懂**：昨天已学会区分「副作用有没有执行」和「状态有没有落盘」。转入 Android 后第一道边界是「功能现在是否就绪」：客户端对象创建成功、手机配置看起来很强，都不够支撑直接显示“本地 AI 已可用”。先让 UI 知道事实和缺口，明天再接最小模型调用。

### 1.1 四层证据：不能压成一个 `isSupported`
| 层 | 应该核验什么 | 不能据此推出什么 |
|---|---|---|
| 厂商 / 系统 / 设备支持 | **具体功能**的官方设备支持页、系统配置、RAM 配置与 AICore 更新情况；解锁 bootloader 等明确限制 | `minSdk` 满足或芯片名字够新，不等于该功能已交付 |
| AICore / SDK 运行时功能状态 | 选定 SDK 客户端的 `checkStatus()`；异常、未知值与状态查询超时显式保留 | `Generation.getClient()` 成功，不等于可生成；不可用也不能直接断言永久不支持 |
| 模型下载状态 | 资产已就绪、可下载、下载中；下载完成后**再查询**当前功能状态 | 有互联网，不等于模型存在；基础模型存在，也不等于所有其他任务功能准备好 |
| 应用隐私 / 网络策略 | 当前前台状态、快照是否仍有效、网络、是否允许下载/上云、用户是否分别同意 | 网络、策略允许、用户同意是不同条件；不能静默上传或自动下载 |

**官方事实〔TOOL〕**：本课以 **ML Kit Direct model access（Beta，`genai-prompt`）→ Gemini Nano → AICore** 为典型。其 SDK 配置要求 Android API ≥26，但官方支持按功能和设备列出；支持列表中有 Pixel 9/10 系列、Galaxy S25 系列等，**这里只举页面内例子，不维护硬编码白名单**。官方还说明模型可用性/版本受 RAM 配置、OS 版本、AICore 更新状态影响；新装/重置后配置尚未准备好也会不可用；解锁 bootloader 不支持。以上为 11-16 读取的文档事实，**不是对你设备的探测结果**。

**两条路线不要混同**：
| 路线 | 支持面与资产归属 | 本课处理范围 |
|---|---|---|
| Gemini Nano / AICore | 由系统服务与厂商支持提供模型能力，ML Kit 查询所选功能状态 | 今日门禁与官方状态映射 |
| 自部署模型 / LiteRT（如 Gallery 示例） | 应用管理模型文件，还需验证模型格式、运行时、后端、内存与具体设备 | 本课不接入；Gallery 的应用 OS 要求不能当 Nano 白名单，也不能证明某模型能跑 |

### 1.2 官方四种状态与应用自己的未知状态
`FeatureStatus` 是官方 **`@IntDef` 整数常量注解，不是 Kotlin enum**。名称、语义来自今日实际读取的参考文档：
| 官方常量 | 含义 | 今日 UI 门禁动作 |
|---|---|---|
| `AVAILABLE` | 功能资产完整下载、就绪 | 若其他门禁满足，显示“可尝试端侧”；离线不必因此阻止本地推理 |
| `DOWNLOADABLE` | 可按请求下载，当前未完整就绪 | 显示“需下载”；在线 + 策略允许 + 用户确认，才建议下载按钮 |
| `DOWNLOADING` | 正在下载 | 显示“正在下载”；不重复启动下载，不提前当可用 |
| `UNAVAILABLE` | 当前功能不可用 | 关闭端侧入口，解释不支持或暂未配置；不要把暂时配置缺失说成永久失败 |
| 应用自定义 `UNKNOWN` / `QUERY_FAILED` | 新状态值 / 证据缺失 / 查询异常或超时 | 安全关闭端侧；显示可观察的原因与重新检查入口，不伪装成功 |

**关键机制**（应用门禁设计〔PROPOSAL〕，不是 Google 的额外 API）：
```text
具体功能的支持证据 + 当前前台/有效期 + SDK 功能状态
                         ↓
              本地 READY / NEED_DOWNLOAD / DOWNLOADING
              UNSUPPORTED / UNKNOWN / QUERY_FAILED / STALE
                         ↓
       下载建议：策略允许 ∧ 联网 ∧ 下载确认（仍不执行）
       云端建议：策略允许 ∧ 联网 ∧ 上云确认（仍不执行）
                         ↓
                由 UI 显式展示；用户点击才进入后续动作
```
- `READY` 表示**可以尝试**，而非已得到模型输出。官方要求 GenAI 推理在应用处于最上层前台时进行，前台服务不能替代；配额/资源/生命周期变化仍可使后续生成失败。
- **可用但离线**：资产就绪且门禁满足时仍可尝试本地推理。**需下载且离线**：只给等待联网提示，不能调用下载，也不能假装模型已经在本地。
- **快照不是永久许可证**：回到前台、用户点击前、模型/配置变化及生成错误后应重查；下载完成也应重新查询。样例 `fresh` 是注入的应用证据，生产环境需要时间戳或失效事件管理，不能一直写死为 `true`。
- **隐私边界**：官方本地处理承诺针对输入、推理、输出；首次配置/资产准备仍可能需要网络。应用自己的云端路由是另一条链路，必须独立受策略与用户同意约束；端侧故障不是上传提示词的授权。

**常见误区（3 条）**：
1. 很多人以为“Android 版本 / CPU 型号达标就能用”，其实厂商交付、具体功能支持、运行时状态与资产准备缺一不可。
2. 很多人以为“初始化成功或 `AVAILABLE` 就是推理成功”，其实创建客户端只证明对象拿到了；`AVAILABLE` 也只是查询时就绪，真正生成仍会失败。
3. 很多人以为“端侧失败且联网，就自动走云端”，其实网络不是隐私授权；禁止上云时必须停留在本地失败/普通编辑功能，不能静默上传。

- **最小可运行代码**：以下完整内容已保存在 `../00_进度/验证/2026-11-16/capability_gate.py`，在 Mac 实跑通过；输出的是 **Host 模拟能力门禁 fixture**，不是设备查询。

```python
"""Host 模拟能力门禁 fixture：不连接手机，不查询 SDK，不联网。"""
from dataclasses import dataclass, replace
from enum import Enum


class Feature(str, Enum):
    # 前四项对应官方 FeatureStatus 的语义；后两项是应用自己的状态。
    AVAILABLE = "AVAILABLE"
    DOWNLOADABLE = "DOWNLOADABLE"
    DOWNLOADING = "DOWNLOADING"
    UNAVAILABLE = "UNAVAILABLE"
    UNKNOWN = "UNKNOWN"
    QUERY_FAILED = "QUERY_FAILED"


class DeviceGate(str, Enum):
    # 应用层环境证据，不是 Google SDK 枚举，也不是芯片白名单。
    OK = "OK"
    BLOCKED = "BLOCKED"
    UNKNOWN = "UNKNOWN"


@dataclass(frozen=True)
class Snapshot:
    feature: Feature
    device_gate: DeviceGate = DeviceGate.OK
    foreground: bool = True
    fresh: bool = True
    online: bool = False
    download_allowed: bool = True
    download_consent: bool = False
    cloud_allowed: bool = False
    cloud_consent: bool = False


@dataclass(frozen=True)
class Decision:
    local: str
    download_advice: str
    cloud_advice: str
    can_attempt_local: bool


def reduce_capability(s: Snapshot) -> Decision:
    """纯函数：只返回 UI 建议，没有下载、云请求或推理副作用。"""
    if s.device_gate == DeviceGate.BLOCKED:
        local = "UNSUPPORTED"
    elif s.device_gate != DeviceGate.OK:
        local = "UNKNOWN"
    elif not s.foreground:
        local = "FOREGROUND_REQUIRED"
    elif not s.fresh:
        local = "STALE"
    else:
        local = {
            Feature.AVAILABLE: "READY",
            Feature.DOWNLOADABLE: "NEED_DOWNLOAD",
            Feature.DOWNLOADING: "DOWNLOADING",
            Feature.UNAVAILABLE: "UNSUPPORTED",
            Feature.QUERY_FAILED: "QUERY_FAILED",
        }.get(s.feature, "UNKNOWN")

    # 有网络不等于允许下载；允许下载也不等于已经得到用户确认。
    download = "NONE"
    if local == "NEED_DOWNLOAD":
        if not s.download_allowed:
            download = "BLOCKED"
        elif not s.online:
            download = "WAIT_NETWORK"
        elif not s.download_consent:
            download = "ASK_CONSENT"
        else:
            download = "OFFER_DOWNLOAD"

    # 即使条件满足也仅建议按钮，不调用云端、不自动计费。
    cloud = "NONE"
    if local != "READY":
        if not s.cloud_allowed:
            cloud = "BLOCKED"
        elif not s.online:
            cloud = "WAIT_NETWORK"
        elif not s.cloud_consent:
            cloud = "ASK_CONSENT"
        else:
            cloud = "OFFER_CLOUD"
    return Decision(local, download, cloud, local == "READY")


def cases():
    base = Snapshot(Feature.AVAILABLE)
    # 每行是独立输入；这里所有状态都是人造 fixture，不是设备实测。
    rows = [
        ("可用且离线", base, ("READY", "NONE", "NONE", True)),
        ("可用且在线", replace(base, online=True),
         ("READY", "NONE", "NONE", True)),
        ("需下载在线未确认", replace(base, feature=Feature.DOWNLOADABLE, online=True),
         ("NEED_DOWNLOAD", "ASK_CONSENT", "BLOCKED", False)),
        ("需下载在线已确认", replace(base, feature=Feature.DOWNLOADABLE,
         online=True, download_consent=True),
         ("NEED_DOWNLOAD", "OFFER_DOWNLOAD", "BLOCKED", False)),
        ("需下载离线", replace(base, feature=Feature.DOWNLOADABLE,
         download_consent=True, cloud_allowed=True, cloud_consent=True),
         ("NEED_DOWNLOAD", "WAIT_NETWORK", "WAIT_NETWORK", False)),
        ("策略禁止下载", replace(base, feature=Feature.DOWNLOADABLE, online=True,
         download_allowed=False, download_consent=True),
         ("NEED_DOWNLOAD", "BLOCKED", "BLOCKED", False)),
        ("正在下载", replace(base, feature=Feature.DOWNLOADING, online=True),
         ("DOWNLOADING", "NONE", "BLOCKED", False)),
        ("不可用允许云建议", replace(base, feature=Feature.UNAVAILABLE, online=True,
         cloud_allowed=True, cloud_consent=True),
         ("UNSUPPORTED", "NONE", "OFFER_CLOUD", False)),
        ("未知且禁止上云", replace(base, feature=Feature.UNKNOWN, online=True),
         ("UNKNOWN", "NONE", "BLOCKED", False)),
        ("查询失败且禁止上云", replace(base, feature=Feature.QUERY_FAILED, online=True),
         ("QUERY_FAILED", "NONE", "BLOCKED", False)),
        ("查询失败未同意上云", replace(base, feature=Feature.QUERY_FAILED,
         online=True, cloud_allowed=True),
         ("QUERY_FAILED", "NONE", "ASK_CONSENT", False)),
        ("不可用离线已同意云", replace(base, feature=Feature.UNAVAILABLE,
         cloud_allowed=True, cloud_consent=True),
         ("UNSUPPORTED", "NONE", "WAIT_NETWORK", False)),
        ("设备环境明确不支持", replace(base, device_gate=DeviceGate.BLOCKED),
         ("UNSUPPORTED", "NONE", "BLOCKED", False)),
        ("设备环境证据未知", replace(base, device_gate=DeviceGate.UNKNOWN),
         ("UNKNOWN", "NONE", "BLOCKED", False)),
        ("可用但快照过期", replace(base, fresh=False),
         ("STALE", "NONE", "BLOCKED", False)),
        ("可用但已离开前台", replace(base, foreground=False),
         ("FOREGROUND_REQUIRED", "NONE", "BLOCKED", False)),
    ]
    return rows


if __name__ == "__main__":
    for name, snapshot, expected in cases():
        actual = reduce_capability(snapshot)
        values = (actual.local, actual.download_advice,
                  actual.cloud_advice, actual.can_attempt_local)
        if values != expected:
            raise AssertionError((name, values, expected))
        print("PASS", name, *values)
    total = len(cases())
    print("PASS 场景表：%d/%d；仅 Host fixture，无 Android 或真机推理" % (total, total))
```

```kotlin
// NOT_EXECUTED：官方契约核对的 Android 接入片段，不是独立 App。
// SDK：com.google.mlkit:genai-prompt:1.0.0-beta4；Android API >= 26。
// 此文件只查询状态，不下载模型，不推理，不上传提示词。
import com.google.mlkit.genai.common.FeatureStatus
import com.google.mlkit.genai.prompt.Generation
import com.google.mlkit.genai.prompt.GenerativeModel
import kotlinx.coroutines.CancellationException
import kotlinx.coroutines.withTimeoutOrNull

// 以下是应用自己的状态，不是 SDK 提供的枚举。
enum class NanoReadiness {
    AVAILABLE, DOWNLOADABLE, DOWNLOADING, UNAVAILABLE, UNKNOWN, QUERY_FAILED
}

data class NanoObservation(val readiness: NanoReadiness, val note: String = "")

suspend fun readNanoReadiness(): NanoObservation {
    var client: GenerativeModel? = null
    return try {
        val model = Generation.getClient()  // 成功创建客户端不代表模型可用
        client = model
        // 2500 ms 是教学选择的 UI 等待预算，不是 SDK 时延承诺。
        val raw = withTimeoutOrNull(2500L) { model.checkStatus() }
        when (raw) {
            FeatureStatus.AVAILABLE -> NanoObservation(NanoReadiness.AVAILABLE)
            FeatureStatus.DOWNLOADABLE -> NanoObservation(NanoReadiness.DOWNLOADABLE)
            FeatureStatus.DOWNLOADING -> NanoObservation(NanoReadiness.DOWNLOADING)
            FeatureStatus.UNAVAILABLE -> NanoObservation(NanoReadiness.UNAVAILABLE)
            null -> NanoObservation(NanoReadiness.QUERY_FAILED, "状态查询超时")
            else -> NanoObservation(NanoReadiness.UNKNOWN, "未识别的 SDK 状态")
        }
    } catch (cancelled: CancellationException) {
        // ViewModel/生命周期取消是控制信号，不吞掉、不变成云端重试。
        throw cancelled
    } catch (e: Exception) {
        // 不用错误文案猜设备型号，也不把异常映射成 AVAILABLE。
        NanoObservation(NanoReadiness.QUERY_FAILED, "状态查询失败：${e.javaClass.simpleName}")
    } finally {
        client?.close()  // 一次性探测样例；该实例不能再用于明日推理
    }
}
```

**接入解释**：Android 将 `NanoObservation` 映射到上面的应用 `Feature` 语义，再合并环境/前台/网络/授权证据。`2500L` 只是假定的 UI 等待预算〔PROPOSAL〕，不是时延实测；查询超时关闭端侧入口，生命周期取消继续向上传播，不能引发云端重试。该一次性函数最后关闭客户端；明日生成需要另一个有效的客户端生命周期，不能复用已关闭对象。默认适配器无需触发 `download()` / `generateContent()`，也没有提示词参数；**本课没有实际运行该函数**。

**踩坑提示**：
- 官方示例在可下载分支直接演示下载，是接入范例而非你的产品授权策略；本课刻意不复制自动下载副作用。
- 不把 `UNAVAILABLE` 按错误文案猜成永久“机型不支持”；初始化配置、系统更新与 bootloader 等原因不同，保留原因缺口并提供复查入口，不建议自动重置 AICore、卸载或重启设备。
- 前台门禁通过后也可能马上离开前台或遇到配额/资源限制。后续生成失败应显式变为失败/待重查状态，不能保留绿色“成功”或偷切云端。
- Host PASS 只说明纯逻辑符合今天的策略；**SDK 二进制编译、超时/生命周期行为与真机推理均 NOT_EXECUTED**，不得把本页当设备验证报告。

  - `NEED_DOWNLOAD` → “需下载模型”；未同意时显示确认说明，离线时按钮禁用。
  - `DOWNLOADING` → “正在下载”；没有真实进度值时不要伪造百分比。
  - `UNSUPPORTED` → “当前功能未支持或配置未就绪”；`UNKNOWN/QUERY_FAILED/STALE` → 展示缺口与重新检查入口。
  - 云端只按 `cloud_advice` 展示“禁止上云／等待网络／请求授权／可选择云端建议”；**按钮不是已经上传**。禁止上云时保留普通文本编辑/手工操作入口。

- **与我的工作结合**：Android 需求“离线润色一小段输入”中，Compose 只渲染不可变状态，ViewModel 收集探测证据后发布新状态；授权变化、回到前台、下载完成都需要可观察的新状态，而非静默改布尔变量。前端/小程序入口也可共用同样的“网络 ≠ 同意”语义，**但不能凭前端可用反推 Android 设备支持**。
- **自检标准**：离线 READY 不误禁用；下载中不重复下载；未知不变成功；未同意云端不显示上传成功；单纯返回云端建议不执行任何外发。练习只做独立 fixture/草图，不修改你的真实工程或设备。
