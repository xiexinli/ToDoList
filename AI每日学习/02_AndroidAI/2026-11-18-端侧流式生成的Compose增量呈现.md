## 1 概念精讲（30 min）
- **一句话定义**：Compose 增量呈现不是把 SDK 流直接交给 UI，而是先把每个正文增量归并成**属于当前请求的完整 UI 快照**，再按生命周期订阅它。
- **它解决什么问题 / 为什么现在必须懂**：昨日的一次完整响应只需校验终点；流式中间态会不断进入界面，错误拼接、丢片、旧请求迟到或退出页面后仍生成，都可能把“半成品”冒充已完成结果。

### 1.1 从官方契约开始，而不是照搬云端 SSE
当天已实读以下签名与语义〔S01/S02/S04/S05〕：
```kotlin
// 官方签名摘录；不是本课伪造的SDK接口。
fun generateContentStream(request: GenerateContentRequest): Flow<GenerateContentResponse>
suspend fun generateContent(
    request: GenerateContentRequest,
    streamingCallback: StreamingCallback
): GenerateContentResponse
interface StreamingCallback {
    fun onNewText(additionalText: String)
    fun onNewThought(additionalThought: String)
}
```
- **Flow 路线（今天采用）**：每次响应只有一个候选；`candidateCount > 1` 抛 `IllegalArgumentException`，所以显式设为 1。中间候选 `finishReason == null`；最后一帧 `finishReason` 非空，例如 `STOP` / `MAX_TOKENS`。收集协程可取消，异常可能中断流。
- **新增，不是累计**：参考页只说 partial/incremental，本身不足以猜 `text` 是全量还是增量；**接入指南的实际示例明确 `fullResponse += newChunkReceived`**，这才是本课追加语义的直接证据。最终帧也先追加其中的文本，再记录结束原因；不能见标记就丢掉最后一个字。
- **Callback 路线（只核对，不接入）**：`onNewText(additionalText)` 给新增正文；挂起函数返回**完整最终响应**。若以后采用它，最终完整正文应覆盖/校准预览，不能再追加一次。完成/失败来自挂起函数返回/异常，接口**没有** `onComplete/onError`。本课不实现 Callback 适配，不订阅、保存或呈现思考过程。
- **不要把本 SDK 的契约推广到所有 SDK**：若另一个适配器明确返回累计快照 `你 → 你好`，就覆盖而非追加。没有文档时写“待核实”，不能用前缀猜测算法自动混用。

### 1.2 唯一主线：增量归并 → 快照 → 受控呈现
```text
用户点击 + 昨日门禁 + 当前最上层前台
  → 新请求代号 id，旧代号失效，取消旧 Job
  → 单飞锁：等待旧请求 finally，再创建新客户端并复查状态
  → SDK Flow："哈" / "哈" / "！"(STOP)
  → 归并正文："哈" / "哈哈" / "哈哈！"（不按文本内容去重）
  → MutableStateFlow<StreamUi>：不可变、累计UI快照
  → collectAsStateWithLifecycle(RESUMED) → Text(state.draft)
  → collect正常完成且 STOP+非空，才进入 SUCCESS → 用户明确点击采纳
任何中断 → 取消/超时/失败状态，隔离草稿，finally尝试close
```
**增量流不能丢片，UI 快照可以合并更新**：SDK 的两个 `"哈"` 是合法重复内容，`distinctUntilChanged()` 会误删；在增量归并前加 `conflate()` 也会掉字。归并后的完整 UI 快照进入 StateFlow，即使 Compose 没画出每个中间帧，最新快照仍有全文。这里不做“每 Token 都重组一次”的性能承诺。

### 1.3 终态、草稿与生命周期（应用策略，不是 SDK 枚举）
| 条件 | 应用状态 | UI 与采纳策略 |
|---|---|---|
| 中间帧或最终标记已到，但 collect 尚未正常完成 | STREAMING | 显示预览，禁止采纳 |
| 正常完成 + STOP + 正文非空 | SUCCESS | 显示正文；仅用户点击采纳才写回 |
| 正常完成 + STOP + 仅空白正文 | EMPTY_RESULT | 保留原输入，禁止采纳 |
| 正常完成 + MAX_TOKENS（含零文本） | TRUNCATED | 未完成草稿，默认隔离，不伪称成功 |
| 正常完成但无标记/OTHER/未知结束原因 | INCOMPLETE | EOF不是成功凭证；隔离草稿 |
| 异常，包括见过STOP后仍发生异常或多余帧 | FAILED | 草稿保留在独立字段，默认不作为正文显示 |
| 用户停止、ON_PAUSE、页面移除、父协程取消 | CANCELLED | 撤销发布权限并传播取消；禁止采纳 |
| 生成预算耗尽 | GENERATION_TIMEOUT | 隔离已有草稿；不自动重试/上云 |

- **安全中断**：官方建议错误时考虑移除已流出的部分输出。本课选择“内存留草稿，但默认隐藏正文、取消采纳资格”，不是把错误字符串拼进回答；生产应用对安全失败可直接清空，不应让用户误认成功。
- **取消分两层**：生命周期感知收集只停 UI 对 StateFlow 的订阅，**不会因此自动取消 ViewModel 已启动的 SDK 推理**。ON_PAUSE/onDispose 明确 `stop()`；ViewModel 清理则取消 `viewModelScope`。本课选择暂停也停止（含旋转），不自动续跑；输入可保存，生成结果不承诺跨进程持久化。
- **旧请求隔离**：先递增请求代号，再 cancel。所有结果/错误/取消发布都检查代号；单飞锁使新实例等旧 finally 完成。锁只保障应用生命周期串行，**不证明设备计算已停止或资源释放成功**。
- **前台与资源**：页面 RESUMED 还需调用方提供应用最上层前台证据；前台服务不替代。`close()` 文档允许多次调用；本课一次请求一次实例，在 finally 尝试关闭，关闭错误独立计数不掩盖原错。超时预算是教学策略，不是 SDK 延迟保证。

**常见误区（3 条）**：
1. 很多人以为“所有流值都是累计答案”，其实这里的官方指南使用追加；不能只看方法名，也不能把 Callback 最终完整响应追加到已有草稿。
2. 很多人以为“去重/丢中间帧更顺滑”，其实在**增量层**会丢合法重复字；应先完整归并，再向 UI 发布累计快照。
3. 很多人以为“停止 UI collect 或拿到 STOP 就完成”，其实在途生成要明确取消，STOP后也要等 collect正常完成；失败和旧请求不得恢复采纳资格。

### 2.1 最小可运行 Host fixture（EXECUTED）
以下与 `../00_进度/验证/2026-11-18/stream_contract.py` 逐字一致。`FakeClient` 输出固定中文，不是真实端侧模型；它验证**归并与状态控制逻辑**，不是 SDK、Compose或性能。`CUMULATIVE`只是对照适配器，Android固定走DELTA。
```python
"""仅Host固定数据：不调用Android、模型、网络；不测推理或性能。"""
import asyncio
from dataclasses import dataclass, replace
from typing import Optional


@dataclass(frozen=True)
class Frame:
    text: Optional[str] = ""
    reason: Optional[str] = None


@dataclass(frozen=True)
class Ui:
    request_id: int = 0
    state: str = "IDLE"
    draft: str = ""
    reason: Optional[str] = None
    notice: str = ""

    @property
    def can_accept(self):
        return self.state == "SUCCESS" and bool(self.draft.strip())


def append_frame(ui, frame, mode="DELTA"):
    """Android已核对为DELTA；CUMULATIVE仅演示别的适配器必须明确声明。"""
    if ui.reason is not None:
        raise ValueError("终止标记后仍有帧")
    if mode not in ("DELTA", "CUMULATIVE"):
        raise ValueError("未知流值语义")
    piece = frame.text or ""
    # 不trim逐片文本，不按内容去重：两个相同词也可能是合法输出。
    draft = ui.draft + piece if mode == "DELTA" else piece
    return replace(ui, state="STREAMING", draft=draft, reason=frame.reason)


def completed(ui):
    if ui.reason == "STOP":
        state = "SUCCESS" if ui.draft.strip() else "EMPTY_RESULT"
    elif ui.reason == "MAX_TOKENS":
        state = "TRUNCATED"
    else:
        state = "INCOMPLETE"  # EOF或OTHER/未知原因，不能当成功
    return replace(ui, state=state)


class FakeClient:
    def __init__(self, frames=(), wait=False, fail=False, feature="AVAILABLE",
                 close_error=False, stubborn=False):
        self.frames, self.wait, self.fail = frames, wait, fail
        self.feature, self.close_error, self.stubborn = feature, close_error, stubborn
        self.events = ["create"]
        self.ready = asyncio.Event()
        self.closed = False

    async def check_status(self):
        self.events.append("check")
        return self.feature

    async def stream(self):
        self.events.append("stream")
        for frame in self.frames:
            yield frame
            await asyncio.sleep(0)  # 让不同任务有机会交错；不是性能数据
        self.ready.set()
        if self.wait:
            try:
                await asyncio.Event().wait()
            except asyncio.CancelledError:
                self.events.append("cancel_received")
                if not self.stubborn:
                    raise
                yield Frame("旧请求迟到文本", "STOP")  # 坏适配器防御fixture
        if self.fail:
            raise RuntimeError("固定失败fixture")

    def close(self):
        self.events.append("close")
        if self.close_error:
            raise RuntimeError("固定释放失败fixture")
        self.closed = True


class Controller:
    """单事件循环模拟ViewModel：请求代号挡旧结果，锁隔离资源生命周期。"""
    def __init__(self):
        self.epoch, self.task = 0, None
        self.ui = Ui()
        self.lock = asyncio.Lock()
        self.history = []
        self.cleanup_errors = 0

    def publish(self, request_id, ui):
        if request_id != self.epoch:
            return False
        self.ui = ui
        self.history.append(ui)
        return True

    def start(self, factory, is_foreground=lambda: True, budget=0.03,
              gate=True, raw="虚构便签"):
        self.epoch += 1
        request_id = self.epoch
        if self.task is not None:
            self.task.cancel()
        self.publish(request_id, Ui(request_id, "CHECKING"))
        self.task = asyncio.create_task(self.run(request_id, factory, is_foreground,
                                                 budget, gate, raw))
        return self.task

    def stop(self):
        if self.task is not None and not self.task.done():
            self.epoch += 1  # 先让旧请求失效，再发送取消
            self.ui = replace(self.ui, state="CANCELLED", notice="仅未完成草稿")
            self.history.append(self.ui)
            self.task.cancel()

    async def run(self, request_id, factory, foreground, budget, gate, raw):
        async with self.lock:  # 新实例等待旧实例finally；不等于设备取消延迟承诺
            if request_id != self.epoch:
                raise asyncio.CancelledError()
            client = None
            local = Ui(request_id, "CHECKING")
            def status(state, notice=""):
                nonlocal local
                local = replace(local, state=state, notice=notice)
                self.publish(request_id, local)
            try:
                if not raw.strip():
                    status("EMPTY_INPUT"); return
                if not gate:
                    status("BLOCKED"); return
                if not foreground():
                    status("FOREGROUND_REQUIRED"); return
                client = factory()
                if await client.check_status() != "AVAILABLE":
                    status("BLOCKED"); return
                async def collect():
                    nonlocal local
                    async for frame in client.stream():
                        if request_id != self.epoch:
                            raise asyncio.CancelledError()
                        if not foreground():
                            status("FOREGROUND_REQUIRED"); return False
                        local = append_frame(local, frame)
                        self.publish(request_id, local)
                    return True
                try:
                    finished = await asyncio.wait_for(collect(), budget)
                except asyncio.TimeoutError:
                    status("GENERATION_TIMEOUT", "仅未完成草稿"); return
                if not foreground():
                    status("FOREGROUND_REQUIRED"); return
                if finished:
                    local = completed(local)
                    self.publish(request_id, local)
            except asyncio.CancelledError:
                status("CANCELLED", "仅未完成草稿")
                raise  # 传播生命周期取消，不转成失败重试
            except Exception:
                status("FAILED", "仅未完成草稿；禁止采纳")
            finally:
                if client is not None:
                    try:
                        client.close()
                    except Exception:
                        self.cleanup_errors += 1  # 不覆盖原始失败/取消


async def main():
    client = FakeClient([Frame("哈"), Frame("哈"), Frame("！", "STOP")])
    controller = Controller()
    await controller.start(lambda: client)
    print("Host固定输出：", controller.ui)
    print("状态：", " -> ".join(ui.state for ui in controller.history))
    print("生命周期：", " -> ".join(client.events))
    print("可采纳：", controller.ui.can_accept, "；端侧推理/usage/性能：未测")


if __name__ == "__main__":
    asyncio.run(main())
```

```kotlin
// 全部是应用状态，不是SDK枚举；不暴露/读取思考过程。
data class StreamUi(
    val requestId: Long = 0,
    val status: String = "IDLE",
    val draft: String = "",
    val notice: String = ""
) {
    val busy get() = status == "CHECKING" || status == "STREAMING"
    val canAccept get() = status == "SUCCESS" && draft.isNotBlank()
}
private class ForegroundLost : Exception()

class NanoStreamViewModel : ViewModel() {
    private val mutableUi = MutableStateFlow(StreamUi())
    val ui = mutableUi.asStateFlow() // Compose只读不可变快照
    private var epoch = 0L
    private var job: Job? = null
    private val singleFlight = Mutex()
    var cleanupFailures = 0
        private set // 本地计数，不记录提示词/输出/原异常消息

    private fun publish(id: Long, value: StreamUi) {
        if (id == epoch) mutableUi.value = value // 拒收旧请求的迟到结果/取消状态
    }

    // 调用方约束：这些入口只在Main线程使用；VM按当前页面作用域创建。
    fun start(raw: String, gatePassed: Boolean, isTopForeground: () -> Boolean) {
        val id = ++epoch
        job?.cancel() // 旧任务先失效；新任务在锁内等待旧finally完成
        mutableUi.value = StreamUi(id, "CHECKING")
        job = viewModelScope.launch {
            singleFlight.withLock {
                currentCoroutineContext().ensureActive()
                if (id != epoch) return@withLock
                var client: GenerativeModel? = null // 资源引用在所有超时块外
                var local = StreamUi(id, "CHECKING")
                var terminal: Int? = null
                var stage = "CREATE"
                fun state(status: String, notice: String = "") {
                    local = local.copy(status = status, notice = notice)
                    publish(id, local)
                }
                try {
                    val input = raw.trim()
                    if (input.isEmpty()) { state("EMPTY_INPUT"); return@withLock }
                    if (input.length > 120) { state("INPUT_TOO_LONG"); return@withLock }
                    if (!gatePassed) { state("BLOCKED"); return@withLock }
                    if (!isTopForeground()) throw ForegroundLost()
                    val model = Generation.getClient() // 不复用昨日已close实例
                    client = model
                    stage = "CHECK"
                    val status = withTimeoutOrNull(2500L) { model.checkStatus() }
                    if (status == null) { state("CHECK_TIMEOUT"); return@withLock }
                    if (status != FeatureStatus.AVAILABLE) {
                        state("BLOCKED"); return@withLock
                    }
                    if (!isTopForeground()) throw ForegroundLost()
                    val request = GenerateContentRequest.Builder(
                        TextPart("请将虚构便签改写成一句简洁中文，只返回改写文本：\n$input")
                    ).apply { candidateCount = 1; maxOutputTokens = 64 }.build()
                    stage = "STREAM"
                    state("STREAMING")
                    val complete = withTimeoutOrNull(10000L) {
                        model.generateContentStream(request).collect { response ->
                            currentCoroutineContext().ensureActive()
                            if (id != epoch) throw CancellationException("旧请求失效")
                            if (!isTopForeground()) throw ForegroundLost()
                            if (terminal != null) error("终止标记后仍有帧")
                            val candidate = response.candidates.singleOrNull()
                                ?: error("候选数量违反单候选契约")
                            // 指南明确 +=：text是新增片段；最终帧也先追加再读结束原因。
                            local = local.copy(draft = local.draft + candidate.text.orEmpty())
                            terminal = candidate.finishReason
                            publish(id, local) // 不trim逐片文本，不按内容distinct
                        }
                        true // 最终标记出现不立刻SUCCESS，等collect正常完成
                    }
                    currentCoroutineContext().ensureActive()
                    if (!isTopForeground()) throw ForegroundLost()
                    if (complete == null) {
                        state("GENERATION_TIMEOUT", "未完成草稿已隔离")
                    } else {
                        val end = when (terminal) {
                            Candidate.FinishReason.STOP ->
                                if (local.draft.isBlank()) "EMPTY_RESULT" else "SUCCESS"
                            Candidate.FinishReason.MAX_TOKENS -> "TRUNCATED"
                            else -> "INCOMPLETE"
                        }
                        state(end, if (end == "SUCCESS") "" else "未完成草稿已隔离")
                    }
                } catch (cancelled: CancellationException) {
                    state("CANCELLED", "未完成草稿已隔离")
                    throw cancelled // 取消不转成成功、重试或上云
                } catch (_: ForegroundLost) {
                    state("FOREGROUND_REQUIRED", "未完成草稿已隔离")
                } catch (error: GenAiException) {
                    state("FAILED", "$stage:SDK:${error.errorCode}；草稿已隔离")
                } catch (_: Exception) {
                    state("FAILED", "$stage:应用契约失败；草稿已隔离")
                } finally {
                    try { client?.close() } catch (_: Exception) { cleanupFailures++ }
                    // close尝试失败不掩盖原错；Mutex解锁不证明设备资源已释放。
                }
            }
        }
    }

    fun stop() {
        if (job?.isActive == true) {
            ++epoch // 发布权限先撤销；旧catch/finally不能污染当前UI
            mutableUi.value = mutableUi.value.copy(
                status = "CANCELLED", notice = "未完成草稿已隔离"
            )
            job?.cancel()
        }
    }
    // ViewModel清理会取消viewModelScope；请求finally负责close，不重复启动推理。
}

@Composable
fun NanoStreamScreen(
    vm: NanoStreamViewModel, // 页面作用域实例，由已有工程的调用方提供
    gatePassed: Boolean,    // 续用第1讲，禁止写死true
    isAppTopForeground: () -> Boolean // 应用最上层前台证据，不是前台服务状态
) {
    val owner = LocalLifecycleOwner.current
    val topForeground by rememberUpdatedState(isAppTopForeground)
    val state by vm.ui.collectAsStateWithLifecycle(
        lifecycleOwner = owner, minActiveState = Lifecycle.State.RESUMED
    )
    var input by rememberSaveable { mutableStateOf("先完成今天最重要的小事") }
    DisposableEffect(owner, vm) {
        val observer = LifecycleEventObserver { _, event ->
            if (event == Lifecycle.Event.ON_PAUSE || event == Lifecycle.Event.ON_DESTROY) {
                vm.stop() // 停UI订阅不等于停止VM里的生成，必须明确取消请求
            }
        }
        owner.lifecycle.addObserver(observer)
        onDispose { owner.lifecycle.removeObserver(observer); vm.stop() }
    }
    Column {
        OutlinedTextField(value = input, onValueChange = { vm.stop(); input = it })
        Button(onClick = {
            vm.start(input, gatePassed) {
                owner.lifecycle.currentState.isAtLeast(Lifecycle.State.RESUMED) && topForeground()
            }
        }) { Text(if (state.busy) "替换当前请求" else "本地生成") }
        Button(onClick = { vm.stop() }, enabled = state.busy) { Text("停止") }
        Text(state.status)
        // 失败/截断/取消草稿留在VM，默认不作为正文展示，更不能自动覆盖原文。
        Text(if (state.status == "STREAMING" || state.canAccept) state.draft else state.notice)
        Button(onClick = { input = state.draft }, enabled = state.canAccept) { Text("采纳") }
    }
}
```

**逐行要点（5条）**：
1. `generateContentStream(request)` 每帧先 `draft + candidate.text` 再读 `finishReason`；相同文本不能删除，空格不能逐片trim。
2. `MutableStateFlow<StreamUi>` 存完整正文快照，`copy()`发布新不可变值；Compose只读最新快照，不自己重复拼接SDK响应。
3. `epoch` 先撤销旧发布权，`Mutex` 串行包住创建到finally；取消旧任务后的新请求不会复用已关闭实例。
4. `complete==true`、正常collect结束、`STOP`和非空同时满足才采纳；见过STOP后异常仍FAILED。
5. `withTimeoutOrNull`吸收自己创建的超时，外层取消继续重抛；ON_PAUSE/onDispose明确stop，finally尝试close，清理错误独立计数。

**踩坑提示**：
- 主线程入口、回调不抛异常、页面作用域VM是调用方接入约束；如果把VM放全局或多页面共享，某页dispose可能取消另一页请求，需要另做作用域设计，不是本课已解决的能力。
- StateFlow合并的是UI快照；不对SDK增量流做 `conflate/distinctUntilChanged`。当前短输出预算64 tokens，简单字符串追加用于教学，不宣传长文本性能。
- 参考页 `Candidate.text` 声明String，说明又提仅函数结果时可能null。本课不启用工具，仍使用 `orEmpty()`防御；不读取思考过程、不产生函数调用。
- 本片段仅状态/生成链路，未加滚动定位/渲染节流/聊天持久化。若真实SDK取消不合作或close失败，可能等待或资源残留；请求代号能防UI污染，不能替代真机资源与延迟验证。
