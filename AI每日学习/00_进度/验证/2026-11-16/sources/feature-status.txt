FeatureStatus
Kotlin
|Java
@IntDef(value = [FeatureStatus.UNAVAILABLE, FeatureStatus.DOWNLOADABLE, FeatureStatus.DOWNLOADING, FeatureStatus.AVAILABLE])
@Target(value = [ElementType.TYPE_USE, ElementType.METHOD, ElementType.PARAMETER, ElementType.FIELD])
annotation FeatureStatus
The status of the feature.
Summary
Constants
 const Int
AVAILABLE = 3
The feature is fully downloaded and ready to use.
 const Int
DOWNLOADABLE = 1
The feature can be downloaded on request.
 const Int
DOWNLOADING = 2
The feature is being downloaded.
 const Int
UNAVAILABLE = 0
The feature is unavailable.
