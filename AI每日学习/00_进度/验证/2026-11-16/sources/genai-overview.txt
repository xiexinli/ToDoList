 Overview of the ML Kit GenAI APIs
 Stay organized with collections
 Save and categorize content based on your preferences.
ML Kit's GenAI APIs harness the power of Gemini Nano to help your apps
perform on-device generative AI tasks. These APIs are built on top of
AICore, an Android system service that manages on-device foundation models
and accelerates inference while keeping user data private.
The ML Kit GenAI API Additional Terms of Service apply to the use of the
GenAI APIs. Developers are solely responsible for the safety of their API client
and their app's user experience.
Key capabilities
ML Kit organizes its GenAI capabilities into the following categories:
Custom generation and agents
Work directly with the Gemini Nano foundation model for custom prompting and
autonomous agentic workflows:
Direct model access (using the GenerativeModel class): Generate text or typed
structured output from custom text-only or multimodal prompts, or manage your
own multi-turn chat history directly by using a List<Content> object with USER and MODEL roles
and a sessionId value, and manage tool declarations directly.
Agentic workflows (using the AgentRunner class): Built on top of
the GenerativeModel class, automating multi-turn session management (including
in-memory conversation history) and multi-step tool-calling loops.
Speech and audio
Transcribe, translate, and synthesize speech audio on-device:
Speech recognition: Transcribe spoken audio content into text in
the same language.
Speech translation: Translate spoken audio into text in another
language in real time.
Text to speech: Synthesize natural-sounding speech audio from
text.
Text and image tasks
Use task-specific APIs optimized for common vision, writing, and search tasks
without prompt engineering:
Image description: Generate a short description of a given image.
Summarization: Summarize articles or chat conversations as a
bulleted list.
Proofreading: Polish short content by refining grammar and fixing
spelling errors.
Rewriting: Rewrite short messages in different tones or styles.
Embeddings: Generate vector embeddings for text and images
using the Embeddings API and pair them with AndroidX AppSearch to find
content by meaning.
Benefits of GenAI APIs
Similar to other existing ML Kit features, GenAI APIs run entirely on-device and
thus provide the following benefits:
Input, inference, and output data is processed locally
Functionality remains the same without reliable internet connection
No additional server cost incurred for each API call
In addition, since GenAI APIs are built on top of AICore and powered by Gemini
Nano, apps and task-specific APIs share the same underlying Gemini Nano base
model on the device. This avoids waiting for a separate model to be downloaded
if Gemini Nano already exists on a device, and in turn conserves storage space.
Learn more about how AICore isolates requests to protect privacy.
Streaming versus non-streaming
ML Kit GenAI APIs offer both streaming and non-streaming options for receiving
results. The streaming API delivers responses incrementally as they are
generated, providing a continuous flow of data. In contrast, the non-streaming
API waits until the entire response is complete before returning it as a single
block.
Choose the streaming API for lengthy responses, as it allows for quicker initial
feedback. The non-streaming API is more suitable for short responses or when
processing results in batches.

Retrieve Gemini Nano version
Different versions of Gemini Nano run on different devices. To return the
version of Gemini Nano on a device, use the getBaseModelName() method.
Note: Different versions of Gemini Nano may return different output from the
same prompt. To ensure your app's use case is compatible with different versions
of Gemini Nano, see Evaluate prompt quality.
Quota per application
AICore enforces an inference quota per app. Making too many
GenAI API requests in a short period will result in an ErrorCode.BUSY
response. When receiving such an error, consider using exponential backoff to
retry the request. Also, ErrorCode.PER_APP_BATTERY_USE_QUOTA_EXCEEDED can be
returned if an app exceeds a long-duration quota (for example, a daily quota).
Background usage
GenAI API inference is permitted only when the app is the top foreground
application. Using the API when the app is not in the foreground, including
using a foreground service, will result in an ErrorCode.BACKGROUND_USE_BLOCKED
response.
